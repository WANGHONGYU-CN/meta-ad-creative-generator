# Meta 素材工厂

给 Meta 投放团队用的素材流水线工具：**找场景（含海报文案与评分）→ AI 生成海报提示词 → 生图 → 看图写文案 → 导出交付包**。

> 本项目为长期维护的生产项目。项目档案、技术决策与开发协作规范见 [CLAUDE.md](CLAUDE.md)。
> 开发在 `develop` / `feature/*` 分支进行，不直接提交 `main`。

## 启动

```bash
cd /mnt/c/Users/yueg0/meta-creative-tool
~/venvs/meta-creative-tool/bin/streamlit run app.py
```

然后在浏览器打开 http://localhost:8501。

> 依赖 venv 放在 WSL 原生磁盘（`~/venvs/meta-creative-tool`）而不是项目目录——项目在 C 盘（9p 文件系统），venv 放这里冷启动要 35 秒+，放 WSL 侧只要 1 秒。重装依赖：`~/venvs/meta-creative-tool/bin/pip install -r requirements.txt`。

## 第一次使用

1. 进「🔑 设置」页，填入 Anthropic API Key（文字环节）和 OpenAI API Key（生图），点保存 → 测试连接
2. 如需修改 AI 的行为，进「📝 提示词管理」页，6 套提示词（主流程 3 套 + 分支 3 套）可在线编辑、可恢复默认
3. 回「🎨 素材工作流」页，按 Step 0 → Step 4 走完流程
4. 以前做过的素材在「🗂️ 历史素材」页可搜索浏览；老数据首次需点页内「重建索引」导入（或跑 `scripts/rebuild_db.py`）

## 工作流说明

| 步骤 | 做什么 | 可人工干预 |
|------|--------|-----------|
| Step 0 | 填产品信息、上传 产品参考图 / 海报风格参考图 / 品牌 Logo（后两者可选：风格图让海报贴近你要的风格，Logo 会原样放进海报角落）、选尺寸（1:1 / 4:5 / 双尺寸）、选文案套数 | — |
| Step 1 | Claude 挖掘主场景 + 细分场景（含目标用户、画面 brief、海报标题/副标题/CTA、评分），候选全部展示、卡片式呈现 | 筛选器按主场景/最低评分过滤展示；点卡片多选场景，「详情」看完整字段；对话框让 AI 修改场景结果 |
| Step 2 | Claude 拿场景的全部变量（目标用户/卖点/画面 brief/广告文字）写出含广告语的英文海报提示词 | 直接改文本，或对话框让 AI 按意见改 |
| Step 3 | gpt-image 并行出图（直接用 Step 2 的提示词，带产品参考图） | 单张重生成；对话框在原图上改（可回退上一版） |
| Step 4 | Claude 看图写多套标题文案并绑定 | 文案表格可编辑；对话框让 AI 整批修改 |
| 导出 | 图片 + manifest.json + 交付表.xlsx 落到 outputs/ | — |

每一处「对话框」都是持续对话：AI 拿**当前结果 + 你的修改意见 + 之前几轮意见**去改，可以一直聊到满意为止。

## 场景库

- Step 1 挖掘出的场景**自动汇总进「🗃 场景库」页**，跨任务累积；再次给同一产品挖掘时，库里已有的场景会自动作为排除清单传给 AI，避免重复。
- 库内可按 关键词 / 产品 / 主场景分类 / 总分区间 / 出图状态 / 投放状态 筛选和排序。
- 两个标签：**已出图**（生图成功后系统自动打）、**投放中**（人工勾选）。
- 勾选若干场景（须同一产品）→「用选中场景创建生图任务」：自动新建一个任务并跳转到工作流，场景已选好，直接从 Step 2 生成提示词开始——不影响任何正在后台跑的任务。
- 删除只删库记录，不影响历史任务的文件。

## 多任务与后台运行

- **任务切换**：左侧边栏可新建任务或在任务间切换，每个任务的全部状态（场景、提示词、图片、文案、对话记录）自动保存在各自的 run 目录里，切走再切回不丢。
- **后台运行**：批量提示词 / 生图 / 批量文案 三个耗时环节提交后即后台运行，当前任务页面锁定并显示进度，**这时可以切到别的任务接着干活**，跑完回来看结果。失败的单项会列出来，重新点生成只补缺失的。
- 注意「后台」指不占页面；关掉 Streamlit 进程任务会停，已完成的部分都已保存。
- **恢复历史任务**：「历史素材」页每个 run 有「载入到工作流继续编辑」按钮，老任务随时捡起来接着做。

## 尺寸说明

- 生图模型 gpt-image-1 原生不支持 4:5，工具会按 1024×1536 竖版生成后**居中裁切为 1024×1280（标准 4:5）**，画质无损。1:1 为原生 1024×1024。
- **双尺寸**不是生成两张不同的图：先出 4:5 母版，再用「尺寸改版」提示词把成品图改成 1:1，**内容与母版保持一致**（AI 重绘适配构图，细节可能有微小差异）。母版重新生成或被修改后，1:1 会自动标记为待重做。

## 文件说明

- `config.json`：API key 与模型配置（仅存本机，已 gitignore）
- `prompts.json`：你修改过的提示词（删除该文件即全部恢复默认）。注意：改完代码或提示词默认值后需重启 Streamlit（本项目关闭了文件热更新）
- `outputs/<日期_产品名>/`：每次生图的交付包
  - `images/` 所有图片，文件名 = `主场景_细分场景_尺寸.png`
  - `manifest.json` 场景 → 提示词 → 图片 → 文案的完整绑定关系
  - `交付表.xlsx` 每套文案一行，与图片文件名绑定，投放直接用
- `logs/app.log`：运行日志（已 gitignore），按天滚动保留 14 天。生图/文案批量跑完有失败时，来这里看完整原因（限流、内容拦截、网关错误等）
- `data/app.db`：SQLite 索引库，供「历史素材」页检索（已 gitignore）。它只是 manifest 的副本——坏了/删了跑一次 `~/venvs/meta-creative-tool/bin/python scripts/rebuild_db.py` 即可全量重建，素材数据不受影响
